# せんたくタグ

衣類やタオルの洗濯表示タグを読み取り、洗い方と洗濯の仕分けを案内する無料Webアプリ(PWA)。

**アプリ本体: https://gryo1240.github.io/sentaku/**

- **タグの読み取り2通り**: ①カメラで撮影してAI読み取り(無料のGemini APIキーを設定タブに登録) ②画面のJIS洗濯表示記号(SVG描画・30種)をタップして選ぶ
- **洗い方の要点表示**: 「洗濯機OK(40℃まで)」「弱コース+ネット」「乾燥機NG」「陰干し」などのチップ+開くと記号ごとの正式な意味
- **クローゼット登録**: 名前・種類(服/タオル/寝具)・持ち主・素材を保存。次からタグを見ずに洗い方がわかる
- **今日の洗濯の仕分け**: 洗うものを選ぶと「標準/ネット・弱/タオル別洗い/手洗い/洗えない」の洗濯機を回す単位に自動グループ分け。乾燥機OK/NGの内訳と糸くず警告つき
- **素材の注意**: 綿の縮み、ポリエステルの糸くず、ウールのフェルト化など素材別アドバイス
- **コツ集**: タオルをふわふわに保つ・糸くず対策・色移り防止など
- **夫婦で同期**(任意): Firebase Realtime Database。設定しなければ端末内のみで動作

データとAPIキーは端末内(同期時は自分のFirebase)にのみ保存。写真はGemini APIに読み取りのためだけに送信されます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(HTML/CSS/JS 1ファイル。洗濯記号はインラインSVGで描画) |
| `manifest.webmanifest` / `sw.js` | PWA化(ホーム画面インストール・オフライン対応) |
| `icon-*.png` | アプリアイコン |

`main` に push すると GitHub Pages に自動デプロイされます。
